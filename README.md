# URL Shortener

A small **URL shortener** built with **Angular 17**, **Clarity Design System**, **Supabase**, and **NanoID**.

Generate short links from long URLs, copy them easily, and redirect to the original URL.

---

##  Features

-  Shorten long URLs into compact links
-  Copy generated links with one click
-  Responsive design for desktop, tablet, and mobile
-  Unique IDs generated with **NanoID**
-  Store data in **Supabase**

---

##  Tech Stack

- **Angular 17** – Frontend framework
- **Clarity Design System** – UI components & styling
- **Supabase** – Backend database
- **NanoID** – Unique ID generation
